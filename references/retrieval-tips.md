# 威科检索经验累积库（retrieval-tips）

> **用途**：用户在威科案例检索 skill 使用过程中口头补充的检索经验，由 agent 自动追加到本文件。下次调用 skill 时，agent 自动 Read 本文件，用 Section A 改写 `--query`、Section B 拼接 `--filter-queries`、Section D 避开反模式。
>
> **格式约定**：每条 tip 固定格式 `[YYYY-MM-DD] 触发场景：动作/结论`
>
> **升级路径**：Section C 的 tip 出现 ≥2 次 或 用户明示"以后都用"，agent 会提示升级到 `references/extra-synonyms.json`（代码层）或 `民事案由_2025.json` 的 aliases 字段。
