# 自然语言抽取规则（nl-patterns）

> 从用户自然语言查询中抽取结构化参数，基于 `nl_parser.py` 实现

---

## 核心策略

Wkinfo 搜索 API 支持 `smartEnabled: true` 和 `synonymEnabled: true`，自带智能匹配和同义词扩展。所以：
- **原始查询** → 直接传给 `queryString`，让威科自己处理语义
- **结构化参数**（时间/法院/审级/文书类型/地域）→ 转为 Lucene 过滤语法，加到 `filterQueries`

**案由匹配是辅助**：基于《民事案件案由规定》(2025 版) 的 514 个第三级案由 + 470 个第四级案由，做关键词倒排索引模糊匹配。匹配结果作为提示/Hint，不强制作为过滤。

---

## 抽取规则

### 模式识别

| 触发词 | 模式 | 输出 |
|--------|------|------|
| `几个` / `几份` / `挑几个` / `要几个` | few | PDF 下载，标黄 |
| `清单` / `汇总` / `全部` / `整理` / `一批` / `下载` | list | Excel 下载，≤200 条 |
| （默认） | list | - |

### 案由（基于倒排索引）

匹配算法：对每个案由/别名（去掉"纠纷"后缀），在用户查询中找子串。命中累积分数：
- 基础分：1.0
- 别名匹配：0.9
- 关键词长度加成：len(keyword) * 0.01

返回 Top-1 作为 `case_cause` 提示。

**典型匹配示例**：
- "建设工程施工合同纠纷" → 第四级 (3) 建设工程施工合同纠纷
- "股东代表诉讼" → ???（不在《案由规定》中，因为它是程序性而非实体性）
- "实际施工人" → 未命中（场景描述，非案由名）

**未命中策略**：把整个 query 传给 wkinfo 的 `queryString`，让它处理。

### 时间范围

| 表述 | 解析结果 |
|------|---------|
| `近三年` / `最近三年` | year_from=now-3, year_to=now |
| `2022-2025` / `2022年-2025年` | year_from=2022, year_to=2025 |
| `2024年以后` | year_from=2024 |
| `2024年之前` | year_to=2024 |
| `2024年` | year_from=2024, year_to=2024 |

### 法院级别

| 表述 | 解析结果 |
|------|---------|
| `最高法院` / `最高法` | 最高人民法院 |
| `高院` / `高级法院` | 高级人民法院 |
| `中院` / `中级法院` | 中级人民法院 |
| `基层` / `基层法院` | 基层人民法院 |
| `北京高院` / `上海一中院` | 具体法院（court_name） |

### 审级

| 表述 | 解析结果 |
|------|---------|
| `一审` / `第一审` | 一审 |
| `二审` / `上诉` / `第二审` | 二审 |
| `再审` / `申诉` / `审判监督` | 再审 |
| `破产` | 破产 |
| `执行` | 执行 |
| `死刑复核` | 死刑复核 |

### 文书类型

| 表述 | 解析结果 |
|------|---------|
| `判决` / `判决书` | 判决书 |
| `裁定` / `裁定书` | 裁定书 |
| `决定` / `决定书` | 决定书 |
| `调解` / `调解书` | 调解书 |

### 地域

覆盖 31 个省级行政区（含直辖市、自治区）。匹配第一个命中的。

### 数量

匹配 `数字 + 个/份/条/起`：
- `5个` → 5
- `10份` → 10
- 默认: few=5, list=200

## 已知限制

1. **场景描述不命中**：用户说"实际施工人向发包人请求付款"，匹配不到"建设工程施工合同纠纷"
   - 缓解：原始 query 直接传给 wkinfo 的 `queryString`（smartEnabled 自动处理）

2. **复合案由**：用户说"金融借款合同纠纷"，可能命中多个相关条目
   - 当前策略：取 Top-1
   - 改进：未来可让用户在 2-3 个候选中确认

3. **方言/简称**：如"借贷"vs"借款"vs"金融借款"，需要同义词扩展
   - 当前策略：依赖威科 synonymEnabled
   - 改进：维护领域同义词词典
